# NIKWAY Academy Local MVP Constitution

Version: 1.0.0 | Ratified for implementation scope: 2026-11-25

1. Preserve existing source, user data, running services and historical evidence. Work in isolated worktrees and loopback services with synthetic fixtures.
2. React/Vite, FastAPI, PostgreSQL and Keycloak form the minimum baseline. Additional engines require an explicit scoped need and verified integration.
3. Verify identity and active tenant membership server-side. Deny by default. Non-bypass database roles and negative isolation tests are mandatory.
4. Model output cannot authorize actions or award credentials. Tools validate schemas, permissions, bounded budgets and kill switch before execution.
5. Evidence precedes acceptance. Exact commit, commands, test result and limitations must be recorded. Independent acceptance cannot be performed by the executor slot.
6. No public deployment, destructive operations, production data, or spend. Merge requires passing checks, independent review and evidence under the user's authority.
7. M03 governance gates precede implementation. Mission planning is not mission acceptance. A local prototype PASS is not current CI or production readiness.

Amendments require recorded rationale and independent review. Current API contracts are in specs/001-local-mvp; historical architecture evidence remains immutable.
