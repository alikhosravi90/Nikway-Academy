# Accumulation roadmap (draft)
1. Inventory existing Academy assets and establish baseline without modifying main.
2. Verify references, dates, source permissions, and benchmark claims.
3. Assign semantic IDs and define bilingual glossary/taxonomy.
4. Build small curated theory/framework/standard cards with cited evidence and review state.
5. Define competency and curriculum schemas + sample PDCA path.
6. Prototype canonical learning-object schema and interchange with Content Factory.
7. Pilot human review, translation, versioning, change impact and automated validation.
8. Connect to Learning OS and evaluate actual learner results.

## Gates
G0 branch and preservation verified;
G1 source and license verified;
G2 expert-reviewed taxonomy and ontology;
G3 schema/interoperability tests;
G4 pilot evidence;
G5 controlled release. All except G0: NOT VERIFIED.

## Example first pilot
PDCA: one competency -> learning objectives -> one learning object -> applied task -> rubric -> learner evidence -> retrospective. Track provenance and reuse across book/audio/video/interactive outputs without claiming learning outcomes before measurement.
