# تغییرات نسخهٔ ۲

- HTML یکپارچه به app، شش feature module، components، domain، data، infrastructure، i18n و styles تفکیک شد.
- React + TypeScript strict + Vite و HashRouter جایگزین innerHTML و متغیرهای سراسری شدند.
- هویت سبز/فیروزه‌ای، فونت، کارت‌ها، مسیر مشاور تحول و داده‌های نمونه حفظ شدند.
- Tailwind و Button/Dialog رسمی shadcn/ui به‌کار رفتند؛ پنجره‌های جزئیات اکنون مدیریت focus و Escape دارند.
- localStorage وضعیت یادگیری به Dexie/IndexedDB با migration یک‌باره و اعتبارسنجی Zod منتقل شد؛ دادهٔ قدیمی حفظ می‌شود.
- تکمیل یک درس با کلیک تکراری پیشرفت اضافی نمی‌سازد. تغییرات هم‌زمان transaction دارند.
- منابع مرتبط اکنون براساس شایستگی فیلتر می‌شوند؛ منبع می‌تواند موضوع مربی را پر کند.
- گفت‌وگو متن امن React است؛ پاسخ ناشناخته صریحاً محدودیت mock را اعلام می‌کند.
- شبیه‌سازی ظرفیت خط و تحویل محدود به تقاضا را جدا نشان می‌دهد. انتخاب مرحله در رفت‌وبرگشت صفحات حفظ می‌شود.
- بازنشانی نیازمند تأیید درون محصول است. فایل backup/import و recovery archive افزوده شد.
- فارسی/RTL و انگلیسی/LTR، ناوبری موبایل، حالت خالی، پیام خطا و وضعیت آفلاین اضافه شدند.
- دارایی‌ها برای استفاده پس از اولین بارگذاری به شکل محلی cache می‌شوند؛ backend و AI واقعی همچنان خارج از دامنه‌اند.
- Vitest، Playwright، lockfile، مستندات معماری و شواهد آزمون افزوده شدند.

## مشکلات یافت‌شده حین توسعه
- TypeScript نصب‌شده گزینهٔ قدیمی baseUrl را نمی‌پذیرفت؛ paths نسبی جایگزین شد.
- مرورگر متناسب با Playwright نصب نبود؛ Chromium آزمایشی محلی نصب شد.
- audit اولیه چهار هشدار متوسط در وابستگی‌های ابزار build داشت؛ glob و minimatch با override به نسخه‌های اصلاح‌شده ارتقا یافتند. نتیجهٔ audit نهایی جدا ثبت می‌شود.
- ایراد overflow فرم مربی در موبایل اصلاح شد و عرض‌های ۳۲۰ و ۳۹۰ آزمون شدند.
- زمان‌بندی تست persistence به پایان قابل مشاهدهٔ ذخیره وابسته شد، نه صرف بازگشت click.
- chunkهای runtime و داده جدا شدند؛ build نهایی هشدار اندازهٔ chunk ندارد.
- انتقال واقعی روی origin قدیمی تأیید شد؛ لینک ?v=2 برای عبور از cache HTML اولیه ارائه می‌شود.
