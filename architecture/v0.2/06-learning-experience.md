## Learning loop
Discover → diagnose → set objective → learn → practice → apply → submit evidence → feedback → reflect → improve.
## Proposed delivery model
40% self-paced, 20% facilitated workshop, 40% applied project as a configurable starting hypothesis, not mandatory timing.
## Design template
Audience, prerequisite, measurable Bloom objective, content, practice, feedback, assessment rubric, accessibility alternatives, evidence and reflection.
## Workshop
Before: preparation and baseline. During: facilitator, breakout groups, shared board and checkpoints. After: artifact submission, feedback and action plan.
## Assessment
Diagnostic, formative and summative; rubric versioning; accommodations and human appeal. AI suggestions never independently issue credentials.
## Acceptance
Pilot learners complete a full journey; measure completion, objective attainment, feedback delay and accessibility barriers without claiming causal improvement.

## Phase 1–2 evidence update — 2026-11-25

### Implemented sample learning loop
Users can open a course, complete a sample lesson, inspect related knowledge, ask the mock tutor, choose a production-line intervention and see competency evidence update. This verifies interaction mechanics only. Learning efficacy, valid mastery assessment, facilitated workshops, real project submission, rubric review and credentials have not been validated or implemented.
