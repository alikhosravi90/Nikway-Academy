# Design System

Status: draft v0.1.0 — proposed, not verified.

Mobile-first responsive shell, Persian RTL and English LTR, semantic tokens for color, typography, spacing and motion. Components: navigation, cards, forms, editor, timeline, workshop board, feedback and accessible dialogs. Use Tailwind/shadcn as implementation baseline. Gate: keyboard, contrast, screen reader and RTL checks against WCAG 2.2 AA.
