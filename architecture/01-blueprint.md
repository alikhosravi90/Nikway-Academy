# Architecture Blueprint

Status: draft v0.1.0 — proposed, not verified.

One portal, one identity, replaceable engines. Next.js/FastAPI/PostgreSQL core; Moodle for courses, Discourse for community, BigBlueButton for workshops, H5P for practice. Open edX optional. Strapi, Wiki.js, PeerTube, Castopod and Onyx are optional adapters. Docker deployment; local-first, cloud-ready. Phase 1 core and learning; phase 2 workshops; phase 3 challenges; phase 4 AI. Gate: end-to-end learning journey.
