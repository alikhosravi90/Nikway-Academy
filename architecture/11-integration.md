# Integration Architecture

Status: draft v0.1.0 — proposed, not verified.

Versioned REST/OpenAPI and asynchronous events; OIDC for identity, LTI 1.3 where supported, xAPI for learning records. Adapters for Moodle, Discourse, BigBlueButton and optional engines. Use idempotency, retry, outbox and contract tests. Gate: verify actual adapter versions and failure recovery.
