## Authority

Core documents define domain intent; specialized documents refine them. Technology stack is the proposed selection baseline (React/Vite rather than Next.js). Conflicts require ADR review, not silent precedence. Historical evidence is not current CI. Governance documents are complementary; release lifecycle refines release gates and action framework refines task execution. No compliance or production readiness claim.
